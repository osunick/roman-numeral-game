🚀 Zero Has No Roman Numeral!

The ancient Romans didn't have a symbol for zero. They started counting from 1!

🏛 Only 5 Letters Needed

For 1 to 100: I=1, V=5, X=10, L=50, C=100.

🔧 The Subtraction Trick

Small before big = subtract! IV=4, IX=9, XL=40, XC=90.

🏢 Still Used Today!

Clocks, movie credits (Episode IV), buildings, Super Bowl numbers, watches!

👥 Build Any Number

Tens first, then ones. 87 = 80+7 = LXXX+VII = LXXXVII!

💡 Fun Pattern

3=III, 4=IV, 5=V, 6=VI. VI is IV backwards!
